# تقرير فحص نقل Maqbali Core v1 إلى الموقع الرسمي

## نطاق الإصلاح

- **9 صفحات رسمية** جُمّعت من قوالب الموقع الحالية: `/` و`/sitemap.html` و`/tools/` و`/contact.html` و`/news.html` و`/cves.html` و`/dji.html` و`/ip.html` و`/speed.html`.
- أُصلحت صفحة الأدوات بإزالة عنصر `<main>` الداخلي الزائد، وتوجيه الشعار إلى `/` وأيقونة الخريطة إلى `/sitemap.html`، وتغيير `noindex,follow` إلى `index,follow`، مع الإبقاء على رابط `/tools/quran/`.
- مُنحت الصفحات الرسمية الثمانية الأخرى إعدادات الروابط وSEO نفسها، دون تعديل ملفات أداة القرآن أو الأصول أو إعدادات Cloudflare.
- خريطة الموقع الرسمية تعرض **17 صفحة** مصنفة بحسب النوع، ولا تعرض روابط `/new/`.
- أضيف ملف `/new/tools/index.html` إلى الحزمة لإصلاح رابط التجربة القديم المفقود؛ هذا الملف التجريبي يبقى `noindex`.
- يبقى مصدر الهيدر والفوتر موحدًا في `core/src/header.html` و`core/src/footer.html`.

## الاختبارات الفنية

| الاختبار | النتيجة |
|---|---|
| بناء الصفحات الرسمية باستخدام `node core/build.mjs` | نجاح؛ 9 صفحات؛ صفر أخطاء بناء |
| البناء التجريبي باستخدام `--preview` | نجاح؛ 9 صفحات تجريبية؛ دون كتابة ملفات الإنتاج |
| فحص أكواد JavaScript عبر `node --check` | نجاح لجميع السكربتات المضمنة |
| فحص بنية HTML | نجاح: هيدر/فوتر/عنصر `main` واحد لكل صفحة |
| فحص robots والروابط الرسمية والثيم والـcanonical | نجاح لجميع الصفحات التسع |
| خريطة الموقع الرسمية | 17 بطاقة وبدون روابط معاينة |
| Chromium محلي: كمبيوتر 1440×900، مظهر فاتح | 9 من 9 اجتازت الفحص؛ لا أخطاء JavaScript أو تمرير أفقي |
| Chromium محلي: هاتف 375×812، مظهر داكن | 9 من 9 اجتازت الفحص؛ لا أخطاء JavaScript أو تمرير أفقي |
| تبديل المظهر عبر الزر | نجاح في 18 حالة اختبار |

### تفاعلات جُربت باستخدام استجابات محاكاة

- التواصل: التحقق من الحقول ثم ظهور نجاح الإرسال **بمحاكاة خدمة Formspree**.
- النشرة المالية: تحميل بيانات تجريبية للذهب والأسهم، مع استدعاءات خارجية مُحاكاة.
- الثغرات: البحث/الترشيح وفتح نافذة التفاصيل ببيانات CVE اختبارية.
- تحديثات DJI: عرض بطاقة الجهاز وفتح تفاصيل الإصدار.
- IP: عرض IPv4 وIPv6 وبيانات المكان المُحاكاة.
- السرعة: تعبئة مثال قيم LTE/5G وتحليلها إلى 8 مقاييس وتقييم عام.
- الأدوات: ظهور بطاقة التلاوة والتوجيه إلى `/tools/quran/`.

## الحدود والتنبيهات

1. لا يمكن إثبات إرسال بريد فعلي، أو تحميل NVD الحقيقي، أو الأسعار المباشرة، أو الموقع الحقيقي، أو سرعة اتصال فعلية من خلال محاكاة API. **اختبر هذه الخدمات بعد نشر ZIP على موقعك.**
2. يلزم التحقق من ظهور صور الشعار والأيقونات في Cloudflare، وهي موجودة أصلًا في مستودع GitHub؛ لم تُضمَّن في ZIP لأنها لم تتغير.
3. ملف الأسواق الأصلي يستخدم رمز وصول خارجي مكشوفًا داخل JavaScript للواجهة، وقد حافظنا على منطق الصفحة كما هو في مرحلة النقل؛ يُنصح مستقبلًا بمناقشة إدارة رمز الخدمة بخادم وسيط بدل تضمينه في صفحة عامة.
4. ملفات HTML الرسمية ستستبدل الملفات الرسمية الحالية فور رفعها، لذلك يمكنك استرجاع النسخ السابقة من سجل GitHub عند الحاجة.
5. استخدام `node core/build.mjs` يعيد إنشاء ملفات النشر الرسمية؛ تغيير الهيدر والفوتر ينعكس **بعد التجميع والرفع**، وليس بمجرد تعديل القالب المنشور.
