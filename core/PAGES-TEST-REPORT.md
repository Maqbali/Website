# تقرير فحص الصفحات — Maqbali Core v1

## نطاق التحديث
- الصفحات المختارة: 3، 5، 8، 11، 12، 13، 14.
- صفحات تجريبية جديدة: 7؛ العدد الإجمالي داخل `/new/`: 9 مع الرئيسية والخريطة.
- لا توجد تعديلات على صفحات الإنتاج القديمة أو ملفات Core v1 المركزية.

## نتائج الفحص
- **فحص البناء:** ناجح (9 صفحات، دون أخطاء بناء).
- **فحص صياغة JavaScript:** نجح في الملفات الستة ذات JavaScript المضمّن؛ صفحة الأدوات لا تحتاج JavaScript خاصًا بعد إزالة مكرر المظهر.
- **اختبارات متصفح مع ردود API محاكاة (كمبيوتر فاتح):** الروابط والأزرار الأساسية وصفحات التواصل والثغرات وDJI وIP والسرعة اجتازت الفحص.
- **الألوان والاستجابة:** لم يُرصد تمرير أفقي بالكمبيوتر ضمن الفحص الناجح. عرض الهاتف والداكن فُحص لبعض الصفحات فقط، ولا يُعد اختبارًا شاملًا لكل الوظائف.
- **صفحة الأسواق:** اكتُشف عنصر يوم مفقود عند إزالة الهيدر القديم وأُصلح بإعادة عرضه ضمن شريط التاريخ. أُعيد تجميعها والتحقق من صياغة JavaScript، ولم يُؤكد تشغيل جميع تدفقات أسعارها الحية بعد ذلك.
- **الروابط الداخلية:** جميع الصفحات التجريبية تشير إلى `/core/v1/`، و`/new/sitemap.html`، و`/new/`، وتحتوي noindex. رابط التلاوة في الأدوات يتجه إلى `/tools/quran/`.

## ملاحظات يجب اختبارها بعد النشر
- إرسال رسالة **اختبارية فقط** عبر Formspree للتأكد من استقبالها في حسابك.
- بيانات الأسواق والرسم البياني وتحميل الأسهم والنفط تعتمد على الخدمات الخارجية والشبكة، ولم يُتحقق منها حيًا.
- تحديث CVE من NVD قد يخضع لحدود استخدام API؛ البيانات المحاكية لا تضمن الاستجابة الحية.
- IP والموقع الجغرافي، ورفع/تنزيل اختبار السرعة لا يصح اختبار نتائجها بمحاكاة الإنترنت؛ جربها من متصفحك بعد النشر.
- النسخ الأصلية محفوظة كما كانت، ولا يمكننا القطع بتطابق كل بكسل من التصميم القديم؛ الهدف توحيد الغلاف مع الإبقاء على مكونات الصفحة.

## ملاحظة أمان
- صفحة الأسواق الأصلية تحتوي رمز وصول API ضمن JavaScript في المتصفح؛ نُقل دون تغيير للمحافظة على الوظيفة. هذه البيانات مكشوفة بطبيعتها لمن يفتح مصدر الصفحة. يمكن مناقشة نقل الطلبات لخادم وسيط في مرحلة منفصلة وبموافقتك.
