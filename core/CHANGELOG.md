# Maqbali Core — سجل الإصدارات

## انتقال الصفحات إلى الإنتاج — 2026-10-20 (ضمن Core v1.0.0)

- نقل الرئيسية والخريطة والصفحات السبع المختارة إلى مسارات الموقع الرسمية.
- إصلاح صفحة `tools/`: إزالة `main` المتداخل، تصحيح روابط الرئيسية والخريطة، والسماح بفهرسة الصفحة الرسمية.
- توليد خريطة الموقع الرسمية مع تصنيف جميع صفحات السجل البالغ عددها 17.
- دعم التجميع الرسمي افتراضيًا (`node core/build.mjs`) والتجريبي اختياريًا (`--preview`).
- فصل مصدر الهيدر والفوتر عن محتوى الصفحات كما هو، دون تعديل `core/v1/core.css` أو `core/v1/core.js`.
- الحفاظ على أدوات القرآن دون تعديل.

## 1.0.0 — 2026-10-19

- تأسيس Core مستقل في جذر الموقع مع الهيدر والفوتر المشتركين.
- اعتماد طابع تصميم صفحة القرآن مرجعًا بصريًا، دون التعديل على الأداة نفسها.
- دعم المظهر الفاتح والداكن تلقائيًا حسب الجهاز، مع حفظ اختيار المستخدم والتوافق مع مفتاح التخزين الحالي `theme`.
- هيدر يتحرك مع الصفحة؛ شعار واسم، أيقونة خريطة الموقع مع تلميح، وزر تغيير المظهر.
- فوتر مرن أسفل الشاشة عند قِصر المحتوى، وبعد المحتوى الطويل: «صمم ♥ Maqbali».
- الرئيسية التجريبية في `/new/` بلا شاشة ترحيب أو شعار مكرر، مع الاحتفاظ بعبارة «مصور عماني» وروابط التواصل.
- خريطة مقارنة تجريبية في `/new/sitemap.html`، تصنّف الصفحات حسب توفر نسخة جديدة.
- سجل صفحات مركزي `config/pages.json`، وقالب فارغ `templates/page-base.html`.
- إنشاء الصفحات مسبقًا بواسطة Node.js دون أي مكتبات خارجية، وفحص الملفات أثناء البناء.
- منع فهرسة جميع صفحات التجربة باستخدام `noindex`.
- دون تعديل الملفات الرسمية أو إعدادات Cloudflare.
